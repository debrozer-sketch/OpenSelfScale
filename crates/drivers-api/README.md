# drivers-api

Контракты периферии весов: трейты драйверов и профили устройства.

Задача крейта: киоск не знает, какой датчик и принтер стоят в конкретной
машине. Периферия описывается профилем (`ScalesProfile` / `PrinterProfile`)
в `config.toml` платформы; драйвер реализует трейт и регистрируется в фабрике
по имени (`kind`). Установка на другие весы = новый драйвер-крейт + правка
конфига, код киоска не меняется.

## Трейты

- `ScalesDriver::poll_once(timeout) -> WeightSample { mass_g, stable }`
- (следующий: `LabelPrinter` — обёртка над escpos с тем же паттерном)

## Дефолты

Дефолтные профили = эталонная весы 192.0.2.10 (Штрих-М Слим 115200,
ESC/POS 19200) — это просто значения «из коробки», не зашитые ограничения.
