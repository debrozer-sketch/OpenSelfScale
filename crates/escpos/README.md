# escpos

Драйвер этикетного принтера ESC/POS (page mode, этикетки с зазором).

Последовательности сняты живым дампом с работающего принтера (19200 8N1,
CP1251). Каждое поле этикетки = пара (ESC $ X, GS $ Y) + текст; штрихкод —
GS k EAN-13. Схема координат совместима с label.xml старого ПО.

## Использование

```rust
use escpos::LabelJob;

let mut job = LabelJob::begin((448, 232));
job.field(0, 0, false, "НАИМЕНОВАНИЕ")?
    .field(79, 180, true, "199,99")?
    .barcode_ean13(2, 160, "210213601350")?;
port.write_all(&job.finish())?;
```

Статус-мониторинг (DLE EOT) встроен: старое ПО его отключало
(`disableStatusCheck=1`), что дало недопечатки и двойную подачу
(см. `audit/PROBLEMS.md`, раздел А). Здесь статус обязателен.
