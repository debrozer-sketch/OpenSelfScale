# Задача: конструктор этикеток для весов OpenScale (один HTML-файл)

Промпт для агента. Выдать ниже целиком.

---

Сделай автономный визуальный конструктор этикеток для термопринтера весов.
Результат — ОДИН файл `label-designer.html`: чистые HTML+CSS+JS, без
фреймворков, CDN, сборки и сетевых запросов. Файл открывается двойным
кликом в любом современном браузере (Chrome/Edge/Firefox), всё работает
офлайн. Весь код — внутри этого одного файла.

## Назначение

Оператор рисует раскладку этикетки для термопринтера (разрешение 203 dpi,
8 дот/мм), указывает размер этикетки в миллиметрах, расставляет поля
мышью и скачивает JSON-файл, который затем кладётся в каталог обмена
весов. Также конструктор умеет открыть уже существующий JSON, отредактировать
его и сохранить (как тот же файл или как новый размер).

## Формат файла раскладки (строго)

```json
{
  "format": 1,
  "name": "58x40",
  "width_mm": 58,
  "height_mm": 40,
  "fields": [
    { "kind": "name", "x": 2, "y": 1, "font": "A", "size": 1 },
    { "kind": "shelflife", "x": 30, "y": 12, "font": "B", "size": 1 },
    { "kind": "text", "text": "СПАСИБО ЗА ПОКУПКУ", "x": 10, "y": 36, "font": "B", "size": 1 }
  ]
}
```

Единицы координат x/y — миллиметры, от левого верхнего угла. `font` —
"A" или "B" (B — узкий мелкий шрифт принтера). `size` — 1 (обычный) или
2 (двойная высота И ширина одновременно). Поле `text` есть только у
kind="text".

Допустимые kind (в этом смысле валидация):
- Данные товара: `name` (название), `plu`, `barcode` (штрихкод EAN-13),
  `weight` (кг с 3 знаками), `price` (цена за кг), `sum` (сумма),
  `date` (дата печати ДД.ММ.ГГ), `time` (время печати ЧЧ:ММ:СС),
  `shelflife` (строка вида «Годен до 20.09.2026»), `cardprice` (вторая
  цена со скидочной картой).
- Служебное: `text` (статический текст из JSON).

## Требования к UI

1. Панель слева: список полей раскладки (kind, координаты, шрифт/размер),
   выбор поля мышью. Кнопки: «Добавить поле» (меню kind), «Удалить поле».
2. Панель свойств выбранного поля: x, y (мм, дробные с шагом 0.5),
   font A/B, size 1/2, для text — редактирование текста (до 48 символов).
3. Холст справа: этикетка в масштабе (зум 2×/4×/8×, авто по ширине окна),
   сетка 1 мм (тонкая) и 5 мм (жирнее), поля — прямоугольники с подписью
   kind и образцовым содержимым. Перетаскивание мышью с привязкой к 0.5 мм;
   стрелки клавиатуры сдвигают выбранное поле на 0.5 мм (Shift — 2 мм).
   Поле нельзя вытащить за границу этикетки.
4. Панель сверху: имя раскладки (авто «WxH», редактируемое), width_mm и
   height_mm (изменение размера пересоздаёт холст, поля вне новой границы
   подсвечиваются красным и при экспорте блокируют сохранение с
   сообщением, какие поля выходят за границу), зум.
5. Кнопки: «Создать новую» (диалог: width/height в мм, очищает поля и
   добавляет стартовый набор: name, barcode, weight, price, sum),
   «Открыть JSON» (input type=file), «Скачать JSON» (Blob + a.download,
   имя файла `label-<name>.json`).
6. Валидация перед скачиванием: format=1, name непустое, width/height в
   диапазоне 20–80 мм и 20–200 мм, обязательные kind присутствуют:
   name, weight, sum, barcode; unknown kind — блокирует сохранение;
   text — непустой. Ошибки — список в модальном окне, не alert().
7. Сохранение черновика в localStorage при каждом изменении (ключ один,
   хранит текущую раскладку); при открытии страницы — предложение
   продолжить с последнего черновика.

## Образцовые данные для превью полей

name: «ВИНОГРАД КИШМИШ ЧЕРНЫЙ КГ»; plu: «PLU 2502192»; barcode: прямоугольник
пропорций EAN-13 с подписью «210213601350»; weight: «1,350 кг»; price:
«199,99 ₽/кг»; sum: «269,99 ₽» (для sum шрифт визуально в 2 раза крупнее
базового размера поля); date: «19.10.26»; time: «18:40:00»; shelflife:
«Годен до 20.09.2026»; cardprice: «Со скидкой: 249,99 ₽»; text — из поля.

Отображение шрифтов приближённое: font A — условно 3 мм на символ при
size 1 (моно), font B — 2 мм; size 2 удваивает. Точная метрика принтера
не требуется, важно приблизительное совпадение занимаемой площади.

## Качество и приёмка

- Никаких внешних запросов: в коде не должно быть http(s):// ссылок на
  ресурсы (кроме, при желании, xmlns-строк SVG).
- Код структурирован: состояние раскладки — один объект, функции рендера
  отдельно от обработчиков, без глобального спагетти.
- Приёмка (проверь сам и покажи результат): открыть файл → создать
  раскладку 58×40 → расставить стартовый набор + shelflife + text →
  сохранить → перетащить поля, убедиться, что координаты меняются →
  скачать JSON → открыть скачанный JSON обратно → все поля на местах →
  удалить поле barcode → попытаться скачать → валидация блокирует со
  списком ошибок → вернуть barcode → скачать успешно.
- В ответе: полный код файла одним блоком + краткое описание структуры
  (state, render, handlers). Не сокращай код на «...» — файл должен быть
  рабочим целиком.

Ограничения: не использовать textarea-«редактор JSON» вместо визуального
холста; не добавлять печать, экспорт PDF, тем, настроек языка — только
перечисленное.
