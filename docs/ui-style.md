# OpenScale UI — текущий стиль (справка для дизайн-прототипов)

Источник: `app/openscale/ui/main.slint` (global Theme, AppButton, DeptTile, PluCard, KbKey).
Платформа: Slint 1.9, киоск-экран 1024×768, сенсорное управление, шрифт DejaVu Sans (моно-вариант для логов/отчётов).

## Философия, как она сложилась

1. **Плоская светлая тема без теней и градиентов.** Глубина передаётся обводкой и сменой заливки при нажатии, а не elevation.
2. **Три уровня поверхностей:** фон окна `#F6F7F9` → карточка `#FFFFFF` → вторичный чип `#EDF0F3`. Нажатое состояние — затемнение того же тона (`#E4E8ED`, `#DDE3EA`).
3. **Обводка — главный разделитель:** 2px `#C9CFD7` у всех интерактивных блоков. Мягкий вариант `#DDE1E6` для внутренних разделителей.
4. **Единая геометрия:** радиус 12px у всех карточек, кнопок и клавиш; вложенные блоки (рамка фото в карточке товара) — 10px. Ничего круглого (нет pill) и ничего острого.
5. **Нажатие = смена заливки.** Ни масштабирования, ни подсветки, ни анимаций.
6. **Цвет — смысловой, не декоративный.** Базовый UI бесцветный (тёмный текст на белом). Цвет появляется только как статус/действие:
   - синий `#2F6FED` — администрирование, основные действия (нажатие `#2456C4`);
   - зелёный `#2E7D57`/`#2FA36B` — успех, скидочная цена по карте; мягкий фон `#F0F7F2`;
   - красный `#B3261E`/`#E23B3B` — авария, опасное действие; мягкие `#F6DEDD`, текст `#7A2E2E`;
   - жёлтый `#E8A13D`/`#E0A100` — предупреждение; мягкие `#F6D9A0`, текст `#6B4A1B`.
7. **Текст — три тона чернил:** основной `#1A1E24`, вторичный `#4A5460`, приглушённый `#A6ADB8` (отключённое, мелкие подписи).
8. **Крупные сенсорные цели:** строки меню 74px, кнопки 56–64px, клавиши ПИН-клавиатуры 58px, шрифты меню/кнопок 22–26px, вес крупного текста 700.
9. **Отступы на сетке 8px:** зазоры между карточками 8px, боковые поля 8–24px.
10. **Попапы-модалки:** затемнение `rgba(10,14,20,0.45)` поверх всего экрана + белая карточка радиус 12px. Сильнее затемнение (0.6) для подтверждений.

## Токены (28 цветов)

- Поверхности: `bg #F6F7F9`, `surface #FFFFFF`, `chip #EDF0F3`, `pressed #E4E8ED`, `pressed-deep #DDE3EA`
- Текст: `ink #1A1E24`, `ink-soft #4A5460`, `ink-faint #A6ADB8`
- Границы: `border #C9CFD7`, `border-soft #DDE1E6`
- Акцент: `accent #2F6FED`, `accent-pressed #2456C4`, `accent-disabled #C3CAD3`
- Успех: `success #2E7D57`, `success-bright #2FA36B`, `success-dark #1E4D3A`, `success-soft #F0F7F2`
- Опасность: `danger #B3261E`, `danger-bright #E23B3B`, `danger-pressed #F2B8B5`, `danger-soft #F6DEDD`, `danger-ink #7A2E2E`
- Предупреждение: `warning #E8A13D`, `warning-strong #E0A100`, `warning-deep #C77700`, `warning-soft #F6D9A0`, `warning-ink #6B4A1B`
- Слои: `overlay rgba(10,14,20,.45)`, `overlay-strong rgba(10,14,20,.6)`, `scrim rgba(255,255,255,.75)`

## Шрифтовая шкала (9 уровней)

`display 96` (вес на главном экране) · `h1 40` · `h2 32` · `h3 26` (заголовки строк меню) · `lg 24` · `body 22` (кнопки, базовый) · `sm 20` (логи, подписи) · `md 18` · `xs 16`.
Исключение: карточки товаров — литералы 9–12px (плотная сетка до 10 колонок, ограничение экрана, не шкала).

## Компоненты

- **AppButton** — единственная кнопка; `kind`: chip (серый) / accent (синий) / success (зелёный) / danger-soft (розовый фон + тёмный текст); disabled — серый фон `border-soft`, текст `ink-faint`. Радиус 12, текст 700, 22px.
- **Строка меню** — белая карточка 74px, радиус 12, обводка 2px, текст `h3` 26px 700 слева с полем 24px; недоступная для роли — opacity 0.45.
- **Карточка отдела (DeptTile)** — цветной блок (цвет из БД), крупный текст по центру, свайп 60–80px = смена страницы.
- **Карточка товара (PluCard)** — белая, 178px высотой: фото в сером блоке радиус 10, название 10px (2 строки), цена; скидочная цена зелёным 11px 700.
- **Клавиатура (KbKey)** — 58px, серо-белые, радиус 12; автоповтор «←» каждые 250мс.
- **Экран состояния/лога** — кнопка «Обновить» + Flickable-список строк, моно-шрифт 20px для логов, 44px строки-плитки для состояния.

## Что ограничено платформой/железом

- Сенсорный киоск без ховера — только pressed-состояние.
- Размер экрана фиксирован (1024×768) — сетка карточек товаров до 10 колонок задана вычислением, не векторной вёрсткой.
- Шрифт DejaVu (кириллица, весовые символы) — смену шрифта надо проверять на покрытие символов №/°/«».
- Иконок нет (только Path-точки) — текстовые подписи везде.

## Для прототипов на арене

Ограничения для нового стиля: сохранить смысловые роли цвета (синий=админ/действие, зелёный/красный/жёлтый=статусы), контраст минимум WCAG AA при 22px+ тексте, сенсорные цели ≥56px, плотная сетка товаров (до 10 колонок × 108px) должна оставаться читаемой, никаких анимаций дольше 100мс (киоск на слабом железе).
