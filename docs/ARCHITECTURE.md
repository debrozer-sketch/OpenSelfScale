# Архитектура ScaleFW

## Слои

```
┌─────────────────────────────────────────────┐
│ Центральный конфигуратор (TypeScript)       │  визуальный редактор
│ веб, вне весов                              │  этикеток/кнопок, парк
└──────────────┬──────────────────────────────┘
               │ HTTPS/SFTP + манифест (sha256)
┌──────────────▼──────────────────────────────┐
│ sync-agent (Rust)      crates/sync-agent    │  staging→verify→publish
├─────────────────────────────────────────────┤
│ datastore (Rust)       crates/datastore     │  SQLite PLU, импорт XML
├─────────────────────────────────────────────┤
│ shtrih-m (Rust)        crates/shtrih-m      │  весы: 115200, LRC, опрос
│ escpos (Rust)          crates/escpos        │  принтер: 19200, page mode,
│                                             │  статус-мониторинг
├─────────────────────────────────────────────┤
│ kiosk (Rust+Slint)     app/kiosk            │  UI, поток веса, печать,
│                                             │  диагностика, калибровка
└─────────────────────────────────────────────┘
```

## Решения и почему

1. **Rust в контуре, TS в центре.** Контур 24/7 на J1900/4 ГБ: без GC,
   без зависимостей в рантайме, один бинарник. Тяжёлый визуальный редактор
   живёт на сервере, где железо не ограничено.
2. **Крейт на устройство.** Драйверы изолированы, тестируются на байтах из
   реального дампа без железа, переиспользуются в CLI-утилитах и тестовом
   стенде.
3. **Манифест вместо флагов.** Старые ready.flg/uploading.flg дали гонки
   (см. PROBLEMS Б2). Публикация — одно rename после verify.
4. **Статус-мониторинг обязателен.** disableStatusCheck=1 в старом ПО —
   источник недопечаток и двойной подачи (PROBLEMS А1/А2).
5. **Калибровка — процедура, не константы.** Прогон тестовых этикеток,
   подтверждение оператором, хранение в БД.
6. **Весовой поток не роняет UI.** Ошибка порта = PortDown в снапшоте
   и переподключение (лечит креш-циклы старого while true).

## Поток взвешивания

```
weight-poll thread ──(poll_once ~1 Гц)──> Snapshot{mass_kg, stable}
        UI timer 200 мс ──читает──> экран
        selected(plu) ──> lookup PLU ──> build_label ──> escpos печать
                                        └──> status() ──> панель
```
